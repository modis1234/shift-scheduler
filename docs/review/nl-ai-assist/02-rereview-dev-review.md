# 내 일정 문장 해석 AI 보조 재검토

대상: `qitem-20261020054429-f87c723b` (이전 리뷰 3건의 수정분)

## Findings

### HIGH — 전체 삭제 허용목록이 부분문자열만 검사해 제외·부정 조건을 무시한다

- 근거: `web-client/src/lib/manager-pattern-ai.ts:52-64`
- `WHOLE_RANGE_DELETE`는 문장 전체의 의미를 제한하지 않고, 문장 어디든 허용 형태가 포함되면 통과한다. 삭제 동사 뒤의 경계도 검사하지 않는다.
- 재현:
  - `병원 일정 빼고 모든 일정 삭제해줘` → 정규식이 `모든 일정 삭제`에 일치
  - `근무 일정은 제외하고 기존 일정 다 지워줘` → `기존 일정 다 지워`에 일치
  - `모든 일정 삭제하지 말고 2일 근무하고 하루 휴무` → `모든 일정 삭제`에 일치
  - 이 입력에서 모델이 `deleteScope: "all"`로 오분류하면 `toCommand()`가 `deleteExisting: true`를 그대로 만든다.
- 영향: 모델 오분류에 독립적인 서버 안전장치가 제외·부정 표현에서는 작동하지 않아, 사용자가 보존하라고 한 일정까지 선택 기간 전체에서 삭제될 수 있다.
- 수정 방향: AI 결과에서 전체 삭제를 활성화하지 말고, 결정적 파서가 문장 앞의 완전한 전체 삭제 절을 실제로 소비한 경우에만 허용한다. 별도 허용목록을 유지한다면 삭제 절의 시작·끝과 뒤따르는 허용 접속 표현까지 완전 일치시키고, 제외·부정 표현을 포함한 나머지 문장이 남으면 거부해야 한다.

### MEDIUM — 제목 검증이 `N일간`·한글 기간을 놓쳐 복수 패턴을 단일 제목으로 등록한다

- 근거: `web-client/src/lib/manager-pattern-language.ts:8-10`, `web-client/src/lib/manager-pattern-language.ts:61-69`
- 분리된 일수 검사는 `N일` 바로 뒤가 공백 또는 문자열 끝일 때만 거부하므로 `3일간`을 허용한다. 한글 기간 `사흘간`도 검사하지 않는다.
- 재현:
  - `parseManagerCommand("2일 주간근무하고 3일간 야간근무하고 하루 휴무")` → `workTitle: "주간근무하고 3일간 야간근무"`인 유효 명령
  - `parseManagerCommand("2일 주간근무하고 사흘간 야간근무하고 하루 휴무")` → `workTitle: "주간근무하고 사흘간 야간근무"`인 유효 명령
- 영향: 여러 패턴 조합은 미지원이라는 계약과 달리, 두 번째 근무 구간이 일정 제목으로 저장되고 사용자 의도와 다른 2일 근무/1일 휴무 반복이 생성된다.
- 수정 방향: 정상 제목 예외를 음절 기반으로 풀기보다, `CORE`가 내부 `하고 + 기간 + 근무` 같은 두 번째 패턴 구조를 제목으로 흡수하지 못하게 문법 단계에서 차단한다. `N일간`, `N일 동안`, `이틀/사흘간` 등 기간 표현도 회귀 입력에 포함한다.

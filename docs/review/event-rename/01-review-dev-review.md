# 문장으로 기존 일정 제목 변경 리뷰

대상: `qitem-20261020081404-e32874bbc430568c`

## 결과

지적할 결함이 없다. **PASS**.

## 확인 근거

- 제목 변경은 문장 전체가 제한된 변경 문법과 일치할 때만 결정적 파서에서 생성된다.
- `쉬는 날`은 한 제목으로 보호되어 내부 `는`을 조사로 잘못 분리하지 않는다.
- 원래 제목과 새 제목은 1~30자 및 기간 표현 금지 검증을 통과해야 하고, 같은 제목이나 색 단어만으로 된 새 제목은 거부된다.
- 반복 등록 문장에 포함된 쉬는 날 제목 지정은 제목 변경이 아니라 기존 반복 등록 경로로 처리된다.
- AI 프롬프트는 기존 일정 변경을 미지원으로 두며 AI 명령에는 rename이 생성되지 않는다.
- 미리보기는 선택 기간 내 제목이 완전히 같은 일정만 `renames`에 포함한다. 부분 일치 제목은 제외되고 종일·시간 일정 모두 정확히 같은 제목이면 포함된다.
- 저장 쿼리는 `store_id`, 양끝을 포함한 선택 기간, `title = from`을 모두 조건으로 사용한다. 다른 매장·기간 밖·부분 제목 일정은 변경하지 않는다.
- 모든 일정 쓰기는 같은 매장 행을 잠근 뒤 현재 snapshot으로 digest를 다시 계산하므로 미리보기 이후 변경은 409로 종료된다.
- 제목 변경과 관련 없는 날짜·시각·메모·색 필드는 유지되고 `updated_at`만 갱신된다.
- 저장 후 달력은 대상 월을 다시 불러와 변경된 제목을 반영한다.

## 직접 확인한 대표 입력

- `쉬는 날은 휴무로 수정` → `쉬는 날`에서 `휴무`로 변경
- `해당 기간 쉬는 날 일정을 휴무로 바꿔줘` → 동일 변경
- `근무를 오픈 근무로 변경해 주세요` → `근무`에서 `오픈 근무`로 변경
- 같은 제목·색 단어 대상 → 거부
- 반복 등록과 쉬는 날 제목 지정이 함께 있는 문장 → 반복 등록으로 유지
- 기존 `쉬는 날`, `쉬는 날 추가`, 시간 지정 `쉬는 날`을 함께 둔 미리보기 → 정확 일치 2건만 변경 대상으로 표시
